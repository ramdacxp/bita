# Bita - Buy it again

Bita is the [Hosi](https://hosix.de/) shopping list, non annoying, SPA, mobile app _kind of_ thing.

Started the [vibe](https://en.wikipedia.org/wiki/Vibe_coding) on 2026-06-26 at the shore of the Baltic Sea in [Binz](https://en.wikipedia.org/wiki/Binz).

## Getting started

```cmd
npm install
npm start -- --open
```
